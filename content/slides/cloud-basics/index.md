A brief (20-minute) entry-level talk aimed at non-developer roles explaining the
context behind the current cloud landscape, a demo showing usage of Terraform,
and some common misconceptions that often make the life of your local DevOps
Engineer more difficult. The target audience has never dealt with a cloud
platform before, and is not necessarily interested in pursuing a career in
DevOps.
